# 18. Project Glossary & Domain Terms

This glossary defines key architectural, 3D spatial, commerce, and database terms used throughout the FunArray platform.

---

## 1. Commerce & Catalog Terminology

* **SKU (Stock Keeping Unit):** A unique alphanumeric identifier assigned to each specific product variant (e.g. `SOFA-KANSO-LINEN`) for inventory tracking and warehouse fulfillment.
* **Product Variant:** A specific purchasable variation of a base furniture item distinguished by color, upholstery fabric, wood finish, and price.
* **Authoritative Pricing:** A security pattern where client-side prices are treated as purely informational; the backend recalculates all item prices, GST taxes (18%), shipping fees, and discounts directly from database records during checkout.
* **Omnichannel Inventory:** A unified stock tracking system that synchronizes central warehouse quantities with localized physical showroom displays (e.g., Delhi Flagship, Jalandhar Gallery).

---

## 2. 3D & Spatial Computing Terminology

* **GLTF / GLB (Graphics Language Transmission Format):** The standard 3D runtime format used by WebGL and Three.js. GLB is the binary container packing 3D mesh geometry, animations, and PBR textures into a single efficient file.
* **USDZ (Universal Scene Description):** A 3D file format developed by Pixar and Apple for native augmented reality rendering on iOS devices via Apple QuickLook.
* **PBR (Physically Based Rendering):** A shading approach that simulates realistic light interaction using roughness, metallic, and normal maps to make wood, leather, and linen look authentic.
* **Placement Reticle:** An animated circular/ring indicator projected onto the detected floor surface in AR that shows the user where the 3D model will land when tapped.
* **Depth Occlusion:** The spatial computing technique of concealing portions of a virtual 3D object when a real-world object (such as a person's leg or a coffee table) is positioned closer to the camera than the virtual item.
* **Floor Horizon Calibration:** The mathematical alignment of a virtual camera's pitch angle, elevation, and field-of-view (FOV) to match the vanishing perspective of a 2D photograph.

---

## 3. Backend & Database Terminology

* **Pessimistic Locking (`PESSIMISTIC_WRITE`):** A database concurrency control mechanism that locks inventory rows during checkout (`SELECT ... FOR UPDATE`), preventing two simultaneous buyers from reserving the same stock unit.
* **Flyway Migration:** Version-controlled SQL scripts (`V1__create_users.sql` ... `V16__create_room_images_and_sessions.sql`) applied sequentially on application startup to ensure schema consistency.
* **S3 Presigned URL:** A cryptographically signed, short-lived URL generated by the backend that grants the client temporary permission to upload large files (3D models, room scans) directly to AWS S3 / MinIO without routing binary data through Spring Boot.
* **Token Blacklisting:** A security mechanism where revoked JWT tokens are registered in an in-memory blacklist upon user logout, blocking subsequent unauthorized requests even if the token has not yet reached its natural expiration.
